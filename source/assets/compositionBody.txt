A tasks file may include others; an include composes its file at the
statement's position, carrying its own vars (outer vars < include
bindings < composed file's own vars):
  var domain = "example.org"

  include "tasks/base.pravic" {       # runs AT this position
      env = "prod"                    # the entry's keys are the
  }                                   # bindings;
  include "files.pravic" {
      vars { three = "three" }        # or grouped under 'vars'
  }                                   # (the same thing)

  An include naming an existing directory uses its main.pravic, like a
  directory argument on the command line.

  import ../tasks/install_gogs         # bundled mode only: copy an
                                      # external file or directory into
                                      # the bundle as its base name
                                      # (project/install_gogs), so
                                      # src/template/run can use it on
                                      # the host; includes inside it —
                                      # or naming it — that are missing
                                      # locally are composed on the
                                      # host.  A bare name that does
                                      # not resolve here is searched in
                                      # the imports paths of
                                      # settings.pravic
